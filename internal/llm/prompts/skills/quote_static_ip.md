# 静态 IP 报价流程

适用：客户问静态 IP / 机房 IP 怎么收费，或已明确静态 IP 并补齐带宽、数量后的报价。

## 步骤

1. 确认产品是静态 IP。类型只有「自建共享」「机房静态」，二者价格完全相同；不要追问共享还是独享，也不要写 `static_type`。
2. 从 `conversation_context`、`user_message` 和 `router_output.slots` 读取带宽、数量。错别字如「贷款」在价格上下文按「带宽」理解。
3. 客户只问「怎么卖/怎么收费」时：先说明按条/月、随带宽和数量档位变化，再问带宽和数量；不要先报单价。
4. 缺少带宽或数量时：只问一个简短问题补齐，不报价、不报区间。
5. 数量档位（只选一个）：1-10、11-30、31-50、51-100、101-200、201-500、501+。
6. 报价阶段：
   - 首次报价：该规格尚无有效数值报价 → 用档位最高价，只给一个单价（元/条/月），月费 = 单价 × 数量。
   - 后续议价：已报最高价且客户明确嫌贵 → 最多用档位最低价。
   - 最低价后仍议价：只说明可提交申请，以审批结果为准，不保证批准。
7. 价格事实只来自 `candidate_pages`；禁止旧价、元/个、百分比折扣、内部底价。

## 停止条件

- 已回答当前问题或已追问唯一缺失字段后停止，不推销场景、不展开完整价表。
