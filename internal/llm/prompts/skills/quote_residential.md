# 住宅 / 独享报价流程

适用：客户问住宅 IP 价格，或说「独享多少钱/独享怎么收费」（当前独享只对应住宅独享）。

## 步骤

1. 确认是住宅 IP 产品线。独享在当前体系只对应「住宅独享」，不是静态 IP 下的独享 SKU。
2. 必须先区分住宅共享还是住宅独享（若客户已明确则不再问）。
3. 带宽仅 5M、10M、20M；单位写「元/条/月」。从上下文读取数量。
4. 只问「怎么收费」时：说明计价维度，再问带宽和数量；缺字段时不报价。
5. 数量档位：1-10、11-30、31-50、51-100、101-200、201-500、501+。
6. 报价阶段同静态 IP：首次最高价 → 议价最低价 → 最低价后只谈申请审批。
7. 事实只来自 `candidate_pages`；禁止元/个、旧折扣档位、内部授权价。

## 停止条件

- 补齐缺失字段或给出当前阶段可对客价格后停止。
