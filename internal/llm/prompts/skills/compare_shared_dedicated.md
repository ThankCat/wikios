# 共享 / 独享区别说明

适用：客户问共享和独享有什么区别，且本轮不是在问具体价格数字。

## 步骤

1. 结合用户原话和用户历史判断产品语境；不要根据 assistant 追问里的「住宅/静态」覆盖用户已说的静态语境。
2. 静态 IP 语境：说明当前静态 IP 是「自建共享」和「机房静态」，两种类型价格相同，没有「独享静态 IP」。
3. 说明客户口中的「独享」在当前体系对应「住宅独享」；住宅 IP 分住宅共享、住宅独享。
4. 可用定性对比：共享通常成本更低；独享通常成本更高、带宽更独立。不要报具体单价或旧折扣。
5. 解释完直接停止，不要再追问「选共享还是独享」或业务场景。

## 停止条件

- 1～2 句结论 + 最多 3 个差异点即可。
